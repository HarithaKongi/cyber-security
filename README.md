# Sentinel Prime — Cyber Security Dashboard

Sentinel Prime is a browser-based cybersecurity dashboard concept that visualizes simulated security events and risk scores in a futuristic monitoring interface.

> **Designed and Developed by Haritha Kongi**

## ✨ Features

- Live-style security event feed
- Simulated threat injection controls
- Risk-score visualization
- Systemic-collapse alert state
- Animated neural-network background
- Uptime counter
- Firebase Realtime Database integration
- Responsive dashboard layout

## 🧩 Security Event Simulation

The dashboard can generate simulated events such as:

- Adaptive entropy evasion
- User behavior friction
- Systemic collapse

Each event includes a generated IP-like value, event type, risk score and timestamp.

These events are intended for **demonstration purposes**, not real-world threat detection.

## 🛠️ Tech Stack

- HTML5
- JavaScript
- Tailwind CSS
- Firebase Realtime Database
- Firebase JavaScript SDK
- Canvas API
- CSS animations

## 🏗️ Architecture

```text
index1.html
├── Dashboard UI
├── Threat simulation controls
├── Firebase Realtime Database
├── Security event renderer
└── Canvas-based neural background
```

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/HarithaKongi/cyber-security.git
cd cyber-security
```

Open `index1.html` in a browser or serve the project through a local web server.

## ⚠️ Project Scope

This is a frontend/security-dashboard concept using simulated events. It does not provide real intrusion detection, threat intelligence, vulnerability scanning or production security monitoring.

Firebase access should be protected with appropriate Realtime Database Security Rules before using the project with real data.
